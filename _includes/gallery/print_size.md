When an image includes DPI information, several print-related features are available.

* Zoom to actual Print Size (`Shift+0`). This requires that the physical size of the display is accurately known. The display size can be calibrated anytime (`Alt+0` / `⌥0`).
* Display [pixel coordinate](#pixel-copy) in a physical unit (in or mm).
* Display [region position and size](#region-selection) in a physical unit.
* Display [grid](#grid) in a physical unit.

Note: most photographs are marked by the camera as 72 DPI, which is generally far too little and makes the image physically very large.
