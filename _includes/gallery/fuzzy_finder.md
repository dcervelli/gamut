Command-palette-style navigation over the file list with thumbnails and helpful metadata per row, `Ctrl+P` / `⌘P` to open. Type a number after `:` to go to an index; negative numbers count from the end of the list. Numeric indexing can be useful after [sorting the list](#file-list).

Bird images from [Fugleramme](https://github.com/arnegiacomo/fugleramme), augmented to include the common name in the metadata.
